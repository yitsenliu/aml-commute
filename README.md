# Anna 的金融證照學習

為 Anna 製作的金融證照學習網站。首頁提供防制洗錢、證券高業、期貨業務、投信法規四科入口；目前開放防制洗錢，其餘為待開放的獨立科目頁。

各科使用 `?subject=aml|securities|futures|funds` 的固定入口。引導與鼓勵以實際閱讀／作答紀錄為依據，以 ALL PASS 為準備目標。既有洗錢防制的儲存鍵、教材及卡片 ID 沿用。

以原始教材為範圍，提供章節閱讀、概念筆記、短篇練習、錯題複習與完整原文。

## 使用

使用持有者收到的專屬連結開啟，無須匯入。教材以 AES-256-GCM 加密；解鎖資訊只放在專屬網址片段及使用者瀏覽器，不提交到此程式庫。請勿公開分享完整專屬連結。

## 學習紀錄

每次操作立即保存，以 localStorage 正本、備援及 IndexedDB 合併復原。網站更新不清除紀錄。清除瀏覽資料、更換瀏覽器與更換裝置仍需下載並還原進度備份。此工具不提供跨裝置自動同步。

## 開發

純靜態 HTML、CSS 與 JavaScript，不含第三方前端依賴或分析追蹤。GitHub Pages 由 main 分支根目錄發布。

驗證：`node --test storage.test.mjs`。
